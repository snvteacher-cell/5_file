Файли та папки: коротко

Це мої підказки. Прочитай їх уважно: вони знадобляться на кожному рівні!

📄 Файл

Файл — це дані (текст, малюнок, пісня, відео), збережені на носії під власним ім’ям.

Ім’я файлу = назва + крапка + розширення: Котик.png

🔎 Розширення підказує тип

  • Текст: .txt .docx
  • Малюнок: .jpg .png
  • Звук: .mp3 .wav
  • Відео: .mp4

Дивись на розширення, а не на назву: Пісня.png — це малюнок!

📁 Папка

Папка допомагає розкласти файли й швидко їх знаходити. У папці можуть лежати файли й інші папки, тому дані на диску схожі на дерево.

🧭 Шлях до файлу

Шлях показує, де лежить файл: диск, потім папки по черзі, а в кінці ім’я файлу. Частини розділяють знаком \

D:\Школа\Математика\Задачі.docx

🚫 Заборонені знаки в імені

В імені файлу чи папки не можна писати: \ / : * ? " < > |

Можна: літери, цифри, пробіли, дужки.

🛠️ Дії з файлами

  • Копіювати — файл з’являється в новому місці й залишається в старому.
  • Перемістити (вирізати й вставити) — файл переходить у нове місце.
  • Перейменувати — змінити ім’я.
  • Видалити — прибрати файл (він потрапляє в Кошик).

Усі дії є в меню, яке відкривається правою кнопкою миші.

⌨️ Клавіші

Ctrl + CкопіюватиCtrl + XвирізатиCtrl + Vвставити

Щоб скопіювати: виділи файл → Ctrl + C → відкрий потрібну папку → Ctrl + V.

🖱️ Провідник

Один клік — виділити. Подвійний клік — відкрити. Нову папку створюють кнопкою «Нова папка» або правою кнопкою миші: Створити → Папку.
